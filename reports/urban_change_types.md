# 삼척시 도시변화 4유형 분석 (집계구 단위)

- 분석 단위: SGIS 집계구 150개 (경계 2024년)
- 건물 지표: GIS건물통합정보 사용승인일·주용도 (승인일 유효 25%, 용도 31%)
- 생활·경제 지표: SGIS 집계구 통계 인구·가구·주택 2015→2024, 사업체·종사자 2015→2023

## 판정 기준

| 유형 | 기준 |
|---|---|
| 신규 개발 집중지역 | 최근(2015~) 신축 비율 상위 25%(≥13%), 최근 신축 10동 이상, 가구 또는 인구 증가 |
| 노후화 누적지역 | 30년 이상 비율 상위 25%(≥66%), 최근 신축 비율 하위 25%(≤5%) |
| 기능 전환지역 | 2004년 이전·2005년 이후 승인 건물의 용도 구성(주거·상업·산업·공공) 상이성 ≥ 0.35 (각 8동 이상) |
| 기능 공백지역 | 건물 20동 이상, 인구 변화 하위 25%(≤-28.1%), 가구 감소, 사업체 또는 종사자 감소, 주택당 가구수 하락, 최근 신축 집중 아님 |

## 해석 시 유의점

- 기능 전환은 같은 건물의 용도변경 이력이 아니라, 새로 지은 건물의 용도 구성이 과거 건물과 다르다는 근사입니다.
- 기능 공백은 빈집 자료가 아니라 인구·가구·사업체 감소와 주택당 가구수 하락으로 추정했습니다.
- 면 지역 집계구는 면적이 넓어 지도에서 크게 보이지만 인구는 적습니다.
- 현존 건물 기준이며 승인일·용도가 없는 건물은 건물 지표에서 빠집니다.
